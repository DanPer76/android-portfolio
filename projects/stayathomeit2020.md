# StayAtHomeIT2020

## Role
Personal Android Project

## Context
Personal Android application created during the COVID-19 lockdown to let users compose a shareable layout made of five photos, each with an accompanying description, in order to capture and share moments from everyday life during lockdown.

## Main Contributions
- End-to-end design and development of the Android application
- Implementation of a five-photo composition layout with text descriptions
- Image selection and handling
- Runtime permission management
- ViewModel-based state management

## Architecture & Patterns
- ViewModel
- Native Android development

## Technologies
- Kotlin
- Android SDK
- ViewModel
- Git
- Bitbucket

## Target
- Android Smartphone
