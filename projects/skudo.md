# Skudo

## Role
Personal Android Project

## Context
Android tablet application for construction-site management, designed to support the tracking of workers, working time and project expenses.

## Main Contributions
- End-to-end design and development of the Android tablet application
- Management of workers and construction-site activities
- Tracking of working time
- Management of project expenses
- Local data persistence
- Support for maps and location-based features

## Architecture & Patterns
- MVC
- Native Android development

## Technologies
- Java
- Android SDK
- Glide
- ButterKnife
- SQLite
- Paging
- Maps
- Location
- Gson
- REST API integration
- Git
- Bitbucket

## Target
- Android Tablet
